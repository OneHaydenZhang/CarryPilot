## 1. 产品是什么

CarryPilot 让用户在 **Hyperliquid** 上做**市场中性的资金费率套利**——买现货 + 做空等额永续，价格涨跌两边抵消，专收永续合约每小时结算的「资金费」。用户不需要盯盘、不需要懂细节：**创建一个 AI Agent，它自主找机会、算成本、开单、盯盘、见坏就撤。**

平台同时是一个**可被其他 AI Agent 调用的研究服务**（A2A / MCP / HTTP + x402 付费），并用 **Injective** 作为身份、燃料与信任层。

## 2. 两类用户

| 用户 | 怎么用 |
|---|---|
| 👤 **交易者 / 普通用户** | 连钱包 → 对话咨询或直接看机会 → 创建 Agent 自主运营，或对话确认后手动下单 → 六大中心观测 |
| 🤖 **AI Agent / 开发者** | 通过 Agent Card 发现 CarryPilot → HTTP/A2A/MCP 免费查费率与机会 → x402 付 USDC 拿完整报告 |

## 3. 核心用户动线

```
连接钱包 → 对话咨询「BTC 能套利吗」 → 看机会卡片（净APR/成本/风险）
   → ①创建 Agent 自主跑  或  ②对话直接下单（可调金额/时长的确认弹窗）
   → 收益中心看持仓 → 风险中心看预测 → Agent 复盘学习
```

## 4. 六大功能中心（详解）

### 💬 对话助手（Chat）
- 大白话提问：「哪些币费率最高」「现在有什么套利机会」「BTC 值得做吗」，**秒回带卡片答案**（费率卡 / 机会卡）
- 机会卡上可直接「下单」或「创建 Agent 跑这个」
- **对话式下单**：说「帮我做 1000u BTC」→ 弹出**可调整的确认弹窗**：
  - ① 调整投入金额（输入框 + $500/$1k/$5k/$10k 快捷档）
  - ② 选择计划持有时长（1天/3天/1周/2周/1月）
  - 组合两腿结构、预期每 8h/每天/毛收入/一次性成本/净收益，随金额与时长**实时重算**
  - 顶部显示风险分级与成本覆盖比；仅风控通过（ACCEPTED）才允许确认
- 顶部实时行情条（BTC/ETH/SOL 当前费率）；空状态有吉祥物引导

### 📡 费率现状中心（Rates）
- Hyperliquid **全市场**实时资金费率、年化（毛）、标记价、未平仓额
- **标签筛选**：有机会 / 多付费 / 空付费 / 费率偏高 / 波动大 / 包装现货 / 仅观察
- 每个标的可展开：现状叙述、近 7 天费率曲线（带坐标）、一键跳 Hyperliquid
- 手动刷新 + 每 10 分钟自动刷新

### 🔬 套利机会中心（Opportunities）
- 确定性引擎**扣完全部成本**后的真实净 APR，有机会的**卡片置顶高亮**
- 过滤标签（全部 / 有机会 / 暂无机会 / 包装现货）
- 点开单个机会看：现状阐述、**对冲结构两腿**、**成本瀑布 SVG 图**、**大白话收益表**（投入 1k/5k/10k/20k 时每 8h/天/周的收益规模）、近 7 天费率曲线、成本覆盖比与回本时长
- 顶部「组合可行性说明」：解释为什么很多币只能观察（HL 站内唯一全对冲结构是现货多+永续空）
- 术语（净APR / 成本覆盖比 / 名义 / 回本 …）都有 **? 问号 tooltip**（定义+大白话+例子）
- 两个行动按钮：**🤖 创建 Agent 跑这个机会** / **💰 直接下单**

### 🤖 Agent 中心（Agents）
- 顶部 **INJ 积分（Agent 燃料）** 面板：余额、消耗速率、**充值套餐**（一键 Cosmos 钱包转 INJ）、**积分流水**（带区块浏览器链接）
- 全局统计：Agent 数 / 运行中 / 合计 PnL / 持仓 / 胜率
- 一个「**+ 创建新 Agent**」按钮 → 弹窗配置：名称、检测标的、**风格**（保守/均衡/激进，决定入场门槛与仓位比例）、资金、**回合数**（≤120）、**结构化 LLM 决策偏好**模板（标的白名单 / 回避条件 / 最低置信度）
- 每个 Agent 卡片：状态、风格、持仓、回合进度、最新决策日志、**预测 vs 实际曲线**
- 点击进详情抽屉：完整配置、**交易记录（历史平仓）**、**沉淀的复盘记忆**、完整决策日志、预测对比大图

### 📈 收益中心（Earnings）
- **当前持仓**明细表（资产 / 来源 / 名义 / 当前费率 / 累计 funding / 成本 / PnL / 持有时长 / 一键平仓）
- PnL 曲线（带坐标轴）
- **平仓记录** + 防篡改 **Receipt 哈希**

### 🛡️ 风险中心（Risk）
- **逐仓风险分级**（费率翻负=HIGH，衰减/亏损越界=MEDIUM）
- 未来 **48h 三情景 PnL 预测图**（费率维持 / 每24h衰减50% / 立即翻负）
- 实盘账户观测（净值 / 清算价 / 保证金 / 近 7 天资金费结算）

### ⚙️ 设置（Settings）
- 钱包连接状态（地址缩略，不暴露细节）
- 交易授权（实盘 API Wallet，只能交易、无法提币，EIP-712 一次性授权）

## 5. Agent 的智能：自主 · 记忆 · 学习

- **每 10 分钟一个回合**：感知费率 → 确定性算成本后净APR → AI 评估可持续性（带复盘记忆）→ 风控硬门 → 开/换/清仓
- **多风格人格** + 结构化偏好注入
- **记忆与学习**：每笔平仓自动复盘、沉淀教训，作为上下文喂给下一次决策 —— 越跑越懂市场
- **动态调仓**：发现更优标的且优势能盖过换仓磨损（2× 安全边际）才换
- **铁律**：AI 只出「建议」，仓位/限额/止损由确定性 RiskGuard 强制；AI 失效自动降级为纯规则

## 6. Injective 经济模型

用户用 **Cosmos 钱包**（Keplr/Leap/OKX）一键转 INJ 充值 → 链上到账自动入积分 → **积分是 Agent 燃料**，每回合消耗 → 形成「用得越多、对 INJ 需求越大」的可持续飞轮。链上身份（ERC-8004 路线）与平仓回执哈希锚定 Injective，构成可验证证据链。

## 7. 安全与合规

- 私钥/密钥只在服务端，UI 不暴露任何地址/账户细节
- 实盘用无提币权限 API Wallet；风控硬顶不可被 AI 越权
- 输出为研究结论与执行记录，**不构成投资建议或收益承诺**；每处都有固定风险提示
