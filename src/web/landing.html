STEP 2

选资产、选风格（保守/均衡/激进）、设资金。模拟盘一键开跑；实盘需授权无提币权限的 API Wallet。

STEP 4

收益中心看 PnL 曲线与结算记录，风险中心盯费率翻转与清算距离。费率恶化 Agent 自动平仓。

套利逻辑，大白话

永续合约价格要贴住现货价，靠的是多空双方每小时互付「资金费」。费率为正时，做多的人付钱给做空的人。 CarryPilot 同时买入现货 + 做空等值永续：币价涨跌两边抵消（市场中性），专门收这笔小时费。 坑在于页面上的「年化 60%」是不扣成本的毛数——四条腿手续费+滑点很容易把它吃光。 所以系统先用保守成本模型杀掉假机会，LLM 再判断费率能不能持续，都通过了 Agent 才真正开单。
