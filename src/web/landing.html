用户动线

从连接钱包到看见收益，五步

STEP 1 🔗

连接钱包

支持 MetaMask / OKX / Rabby 等注入式钱包（EIP-6963 自动发现）。仅签名做身份，无交易无 gas。新用户送体验积分。

STEP 2 📡

看清市场

费率现状中心看全市场实时费率与 7 天曲线；套利机会中心看扣完成本后哪些标的真的有机会、投入 1000-20000u 每天/每周能赚多少（大白话）。

STEP 3 🤖

创建 Agent

选标的、风格（保守/均衡/激进）、资金、回合数（≤120），还可以给 LLM 写自定义指令。模拟盘一键跑；实盘需授权无提币权限的 API Wallet。

STEP 4 ⚙️

Agent 逐回合决策

每 60 秒一回合：拉最新费率 → 成本引擎 → LLM 评估 → 风控硬门 → 开仓/换仓/清仓/观望，每一步的理由写进日志，预测线和实际线同图对比。

STEP 5 📈

观测与结算

收益中心看 PnL 曲线与平仓 Receipt；风险中心看风险分级与 48h 三情景预测。费率翻负 Agent 自动清仓。

数据流动线

AI 只负责判断与解释，数字与下单全部由确定性代码完成

五大中心

📡 费率现状中心

HL 全市场实时费率 + 7 天费率曲线 + 一键跳转 HL；每个标的可展开阐述：现在什么情况、能不能做。

🔬 套利机会中心

有机会的置顶，过滤标签筛选；展开看两腿组合、成本瀑布、投入 1000-20000u 的每 8h/天/周收益规模。

🤖 Agent 中心

风格/回合/自定义 prompt；逐回合决策日志讲清为什么开、为什么换、为什么撤；预测 vs 实际曲线对比。

📈 收益中心

PnL 曲线、平仓 Receipt 哈希、INJ 积分充值、实盘 API Wallet 授权。

🛡️ 风险中心

逐仓风险分级 + 未来 48h 三情景（维持/衰减/翻负）PnL 预测图；实盘清算价与保证金观测。
