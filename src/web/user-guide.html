USER GUIDE

从连接钱包到收到第一笔资金费，全流程

这份指南按真实操作顺序走一遍：每一步在哪个 tab、点什么按钮、弹窗里要做什么。凡是需要你亲自动手的地方（签名、转账、点某个按钮）都用蓝色框标出来——这些是系统不会替你做的事。

① 连接钱包 ② 看行情 ③ 燃料 ④ 创建 Agent ⑤ 运行中 ⑥ 复盘 常见问题 配合清单
1

连接钱包

右上角「连接钱包」→ 选钱包 → 签一个消息。全程不发交易、不花 gas、不碰你的资金。

点顶部导航栏的 连接钱包 按钮，弹出选择框：

  • 电脑端：浏览器装了 MetaMask / OKX Wallet / Rabby 等插件时，会自动列出（EIP-6963 多钱包识别），点你要用的那个
  • 手机端：如果是在普通浏览器（非钱包内置浏览器）打开本站，会给你 MetaMask / OKX / Trust 的深链按钮——点一下会跳转到对应钱包 App 内打开本站
🙋 需要你配合钱包会弹出一条待签名消息（personal_sign），内容是一次性 nonce，用来证明这个地址是你本人控制。点「签名」确认即可——这不是转账，钱包不会显示 gas 费。手机端如果是从深链跳转过去的，进入钱包内置浏览器后要重新点一次「连接钱包」才会弹出签名。

签名成功后，右上角会显示你的地址缩写（如 0xAb12…9f3D），登录状态保存在浏览器本地，刷新页面不用重连。

2

看懂费率现状 / 套利机会

这两个 tab 不需要连钱包，谁都能看。建议先在这两页转一圈，搞清楚现在值不值得开 Agent。

📡 费率现状：全市场资金费率表，标签筛选（有机会 / 多付费 / 空付费 / 费率偏高 / 波动大 / 包装现货 / 仅观察）。点一行会展开该标的近 7 天的小时费率曲线。

🔬 套利机会：每张卡片是引擎算出来的一个候选组合。绿色高亮的是「扣完成本仍为正」的真实机会；点卡片展开看对冲结构（现货腿 + 永续腿）、成本瀑布图（一步步扣手续费/滑点/准备金）、以及投入 $1,000～$20,000 的大白话收益表。

💡 全市场经常没有机会——这不是 bug。资金费率是波动的，引擎宁可诚实地说「暂无机会」也不会为了有内容显示而编个数。有 Agent 在跑的话，它会在机会出现时自动抓住，不需要你盯盘。
3

准备燃料（INJ 积分）

Agent 每运行一回合（10 分钟）消耗积分，积分从哪来、怎么加，这一步说清楚。

连上钱包后系统会自动送 500 点新用户体验积分（约够跑 2500 回合，虚拟盘随便试不用充值）。想加更多，或者体验积分用完了，去 设置 → INJ 积分：

充值流程
  1. 页面上会显示「金库地址」和「你的 Injective 原生地址」（由你登录的 EVM 地址自动推导，同一把私钥控制）
  2. 从你自己的钱包，用上面那个 Injective 地址转一笔原生 INJ 到金库地址
  3. 回到页面，点 「我已转账，扫描到账」 按钮
🙋 需要你配合（两步都不能少）① 转账这一步是你在自己的钱包 App / Injective 客户端里完成的，本站不会替你转；② 到账不是自动的——转完之后必须回来手动点一次「我已转账，扫描到账」，系统才会去链上核对交易并加积分（按 txhash 去重，多点几次也不会重复入账，放心点）。

汇率与消耗：1 INJ = 100 积分，每个运行中的 Agent 每回合（10 分钟）消耗 0.2 积分。

4

创建 Agent

Agent 中心 tab，先选工作区（虚拟盘 / 实盘），填表单，点创建。两条路径前置条件不一样，展开看你要走哪条。
字段说明
名称随便起，方便你在列表里认出它
检测标的选具体币种，或「全市场自动选」让引擎自己挑当前最优的
风格保守（净APR≥15%才进场·30%仓位）／均衡（≥8%·50%）／激进（≥4%·80%）——决定入场门槛和仓位比例
资金这个 Agent 可用的名义本金上限；虚拟盘最多 $100,000，实盘硬顶 $2,000（RiskGuard 强制，改不了）
回合数生命周期，10~120 回合可选（120 回合 ≈ 20 小时），用完自动收尾平仓
LLM 决策偏好可选，用预设模板或自定义「偏好标的/回避条件/最低置信度」，在系统风控框架内生效，不能让 AI 加杠杆或改数值

每个用户最多同时开 5 个 Agent。填完点 「创建并启动」，会立刻触发第一次决策（不用等 10 分钟）。

🧪 虚拟盘（新手从这条开始）

  1. 模式选 PAPER
  2. 直接创建，零风险，用的是设置里的虚拟资金额度（默认 $10,000，想改去 设置→虚拟盘账户）
  3. 不涉及真实资产，唯一消耗的是积分

⚡ 实盘（真实下单，两个前提缺一不可）

  1. Hyperliquid 账户要先有 USDC——这个要你自己去 app.hyperliquid.xyz 入金，CarryPilot 不负责充钱进去
  2. 回本站 设置 → 交易授权，点「授权实盘 API Wallet」，钱包会弹出另一种签名（EIP-712 结构化签名，跟登录时的签名不是一回事）——确认签名
  3. 系统会生成一个只属于你的 API Wallet（只能下单交易，没有提币权限），之后创建 LIVE Agent 才不会被拒绝
🙋 需要你配合没做完实盘两步就选 LIVE 模式创建 Agent，后端会直接拒绝并提示「实盘模式需先完成 API Wallet 授权」——不会帮你跳过。这一步是一次性的，授权过一次之后所有实盘 Agent 都能用。
5

Agent 运行期间，你要做什么

正常情况下几乎不用管。它每 10 分钟自己：拉最新费率 → 算成本 → AI 判断 → 风控过滤 → 开仓/换仓/清仓/观望，每一步理由都写进日志。

你能做、也可能需要做的事：

  • 点 Agent 卡片进详情抽屉，看完整配置、交易记录（历史平仓）、沉淀的复盘记忆、决策日志
  • 手动 「停止」 / 「启动」：停止后如果有持仓会先平仓再停；启动会让它从下一回合继续跑
  • 手动 「平仓」：不想等 Agent 自己判断退出时，直接对当前持仓点平仓
  • 「删除」：仅对已停止且空仓的 Agent 可用
⚠ 会打断运行、需要你回来处理的情况积分（燃料）耗尽时，Agent 会自动暂停并在日志里写「积分不足，Agent 已暂停」——它不会在你充值后自动恢复，你需要回到设置充值 INJ 积分，再回 Agent 中心手动点「启动」。回合数用尽（到 120 回合上限）也会自动收尾平仓并停止，同样需要你决定是否重新创建。
6

观测与复盘

两个只读中心，随时看，不需要操作。

📈 收益中心：全部 Agent 合计的 PnL 曲线、每笔平仓记录（含防篡改 Receipt 哈希）。

🛡️ 风险中心：当前持仓的风险分级（LOW/MEDIUM/HIGH）、未来 48 小时三种情景（费率维持/衰减/翻负）的 PnL 预测曲线；完成实盘授权后这里还会显示「实盘账户观测」——Hyperliquid 账户净值、可提金额、真实持仓与近 7 天资金费结算记录。

常见问题

连接钱包要花 gas 吗？

不用。登录只是签一条消息（personal_sign），不上链、不花 gas。只有「实盘授权」（EIP-712）和你自己转 INJ 充值这两个动作涉及你的钱包在做真实操作，但授权签名本身也不花 gas，只有转账会花你自己钱包所在链的 gas。

虚拟盘和实盘的数据会混在一起吗？

不会。Agent、持仓、收益、风险统计按工作区（PAPER/LIVE）完全隔离，Agent 中心顶部切换 tab 看的是哪边的数据一目了然。

转了 INJ 但积分没到账怎么办？

先确认转的是原生 INJ、转到的是页面显示的金库地址、发送方是你登录钱包对应的 Injective 地址；再等一下（链上确认需要时间）重新点「扫描到账」。多点几次不会重复入账，按 txhash 去重。

实盘最多能亏多少？

单个实盘 Agent 资金上限硬顶 $2,000，这是代码里强制的 RiskGuard 限制，前端和后端都改不了。授权的 API Wallet 没有提币权限，即使私钥泄露对方也提不走本金，只能交易。

为什么创建 Agent 后一直空仓？

正常——引擎只在「扣完成本后净APR为正」时才开仓。费率不够高的时候，Agent 会诚实地保持观望，日志里会写明当前不满足哪个门槛，不会为了有动作而硬开一个亏钱的仓位。
