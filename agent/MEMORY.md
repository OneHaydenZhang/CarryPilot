- x402（P0，已验证握手可行）：`@injectivelabs/x402` EIP-3009 gasless USDC；testnet USDC `0x0C38…4C5d`(eip155:1439)；spike `scripts/x402-spike.ts` 证明 402 报价握手跑通；结算待海外服务器+funded USDC

## 演进主线（为什么长这样）

1. **知识期**：先沉淀 HL/INJ 技术知识库（docs/knowledge/）+ 工具链，确立"确定性外壳 + LLM 内核"铁律
2. **验证期**：v0.1 扫描器证明"毛APR幻觉"——大多数机会扣完成本是负的，诚实拒绝成为产品核心主张
3. **产品期**：用户反馈驱动收敛：只做 HL 单所（放弃跨所）→ Maneki 式 Agent 架构（用户创建 Agent 代为操作）→ 五中心动线
4. **可信期**：虚拟/实盘彻底隔离、回合制+积分燃料（INJ 经济飞轮）、复盘记忆、预测vs实际可视化
5. **对外期**：本 agent/ 目录 + Agent Card，让 CarryPilot 自身可被 A2A 调用

## 不可回退的决策

- tick=10min（改动需同步 UI 文案与验收）；触发式首回合（triggerEngineSoon）
- 公开仓库：密钥/IP/模型版本号永不入库入 UI
